# Expo example

The same screens as [`../example`](../example) (the bare React Native app), running on **Expo SDK 57** (React Native 0.86). Use it to check the scanner works in Expo development builds.

The library is linked from the repo root (`link:..`) and Metro loads its TypeScript source from [`../src`](../src), so library changes hot reload here without a rebuild. Native changes (`../android`, `../ios`) need a new native build.

This is a standalone Yarn project, not a workspace of the repo root. That keeps Expo's React Native version separate from the root's and from `../example`'s.

## Run

The scanner uses native code, so it needs a development build; it can't run in Expo Go.

```sh
cd example-expo
yarn
npx expo run:android   # or: npx expo run:ios
```

`ios/` and `android/` are generated by `expo prebuild` and git-ignored. Scanning needs a real device; simulator and emulator cameras don't exercise ML Kit or Vision.

## Test

```sh
yarn test        # Jest (jest-expo + React Native Testing Library)
yarn typecheck
```

The tests replace the native `ScannerView` with a plain `View` (see [`jest.setup.tsx`](jest.setup.tsx)). A test can then check the props a screen passes to the scanner (torch, zoom, `pauseScanning`, strategy, focus area) and fire `onBarcodeScanned` / `onScannerError` the way the native side would. They cover:

- **Navigation:** every Home card opens its screen, and the coming-soon cards don't navigate.
- **Camera permission:** checking, granted, denied then granted, blocked, and unavailable.
- **Scanning:** each scan shows an alert and pauses the scanner, dismissing the alert resumes it, empty scans are ignored, and native errors are shown.
- **Per-screen controls:** torch, zoom, focus area and barcode frames.
- **Scan strategy:** switching strategy, the list of results, and stop/resume.
- **Camera info:** loading, device details, refresh, and error with retry.

## Differences from `../example`

- `StyleSheet.absoluteFillObject` was removed in React Native 0.86, so `FullScreenExample` uses `StyleSheet.absoluteFill`.
- Camera permission on iOS is configured through the `react-native-permissions` config plugin in `app.json` instead of a Podfile.
